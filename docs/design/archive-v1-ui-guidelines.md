# 智慧档案 V1 前端 UI 规则

## 1. 适用范围与实现状态

本文约束 `mini-rag-milvus-vue` 的智慧档案工作台视觉与前端行为。

- 已接入：FR-030 项目创建、列表、读取、修改、空项目删除，FR-031 清单读取、创建、修改和删除，以及 FR-032/033 项目文档上传、处理列表、首次解析和失败重试；
- 页面未接入：FR-034～FR-041；未接入页面必须显示接口边界提示，不能渲染为真实业务结果；
- 除注册、登录、刷新和健康检查外，所有项目请求都携带后端验证的 `Authorization: Bearer <Access Token>`；
  `X-User-ID` 不再是受支持的身份头。客户端不得提交或覆盖 `owner_id`、`user_id`、`kb_id`。

## 2. 颜色变量

| 语义 | CSS 变量 / 颜色 | 使用位置 |
|---|---|---|
| 主色 | `--primary: #1A73E8` | 按钮、链接、选中指示条、已解析状态 |
| 侧栏 | `--sidebar: #1E293B` | 固定导航背景 |
| 侧栏文字 | `--sidebar-muted: #CBD5E1` | 非激活菜单 |
| 成功 | `#F0FFF0` / `#2D8B2D` / `#52C41A` | 已满足、已确认 |
| 缺失/失败 | `#FFF1F0` / `#D32F2F` / `#FF4D4F` | 缺失、解析失败、失败统计 |
| 待人工确认 | `#FFF7E6` / `#FA8C16` | 待人工确认、待重新确认 |
| 未提供 | `#F5F5F5` / `#8C8C8C` | 可选清单项未提供 |
| AI 处理 | `#F0F8FF` / `#1A73E8` | 已解析、建议失败、AI 来源标识 |

统计卡片使用左侧 4px 装饰条，而不依赖颜色单独表达状态。

## 3. 文档状态与 UI 别名

| 后端枚举 | UI 别名 | 主要操作 | 备注 |
|---|---|---|---|
| `UPLOADED` | 待解析 | 开始解析 | 尚未产生解析快照 |
| `PARSE_FAILED` | 解析失败 | 重试解析 | 失败原因只显示稳定错误摘要 |
| `PARSED` | 已解析 | 生成 AI 建议 / 开始人工草稿 | 不显示为“待确认草稿” |
| `SUGGESTION_FAILED` | 建议失败 | 重试建议 / 开始人工草稿 | 不把失败伪装成可确认草稿 |
| `PENDING_CONFIRMATION` | 待人工确认 | 继续核验 / 查看建议 | AI 与人工来源只作为次要标记，不新增状态 |
| `CONFIRMED` | 已确认 | 查看正式档案 | 仅进入正式目录、检索和问答范围 |
| `PENDING_RECONFIRMATION` | 待重新确认 | [TODO] | 具体主操作和列表筛选归属须随 FR-036 状态机实现冻结 |

首页“待人工确认”统计的精确聚合口径也在 FR-036 实现后冻结。当前前端不显示
没有 API 响应支撑的状态数字。

## 4. 清单状态

| 派生状态 | UI 别名 | 颜色 |
|---|---|---|
| `SATISFIED` | 已满足 | 成功绿色 |
| `MISSING` | 缺失 | 红色 |
| `NOT_PROVIDED` | 未提供 | 灰色 |

五项内置虚构模板始终按以下顺序展示：项目合同、设计说明、施工方案、项目会议纪要、
验收报告。该模板不代表真实工程项目的法定或行业归档规则。

## 5. 导航与路由

| 菜单 | 路由 | 当前状态 |
|---|---|---|
| 总览 | `/` | 工作台与项目 CRUD 已实现 |
| 项目与清单 | `/projects/{id}/checklist-items` | FR-031 已接入；状态只采用后端响应 |
| 文档处理 | `/projects/{id}/documents` | FR-032/033 已接入；操作按钮严格取决于服务端状态 |
| 正式档案 | `/projects/{id}/archives` | 页面占位，等待 FR-036/038 |
| 智能检索 | `/projects/{id}/archive-questions` | 页面占位，等待 FR-039 |
| 审计日志 | `/projects/{id}/audit-logs` | 页面占位，等待 FR-041 |
| 项目设置 | `/projects/{id}/settings` | FR-030 修改与删除已实现 |

页面加载时必须验证 URL 中的 `{id}` 属于当前项目列表；不允许用另一个实际选中项目
渲染伪造的 URL 范围。
